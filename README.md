# 🎁 Birthday Wishlist App

Веб-приложение для виш-листа на день рождения. Гости могут выбирать подарки, а именинница видит всё, но не знает, что уже занято.

## 🚀 Быстрый старт

### 1. Установка зависимостей

```bash
# В корневой папке проекта
npm run install:all
```

### 2. Запуск

```bash
# Запуск всех серверов (backend + frontend + admin)
npm run dev
```

Или по отдельности:

```bash
# Backend (http://localhost:3001)
npm run dev:backend

# Frontend для гостей (http://localhost:3000)
npm run dev:frontend

# Панель именинницы (http://localhost:3002)
npm run dev:admin
```

### 3. Инициализация данных

После первого запуска backend, отправьте POST запрос для заполнения базы данных:

```bash
curl -X POST http://localhost:3001/api/seed
```

Или откройте в браузере: `http://localhost:3001/api/seed`

## 📱 Ссылки

| Приложение | URL |

## 🎯 Как это работает

1. **Гости** заходят на http://localhost:3000, видят список подарков
2. Нажимают «Хочу подарить» и вводят своё имя
3. Подарок помечается как занятый (но имя не показывается!)
4. **Именинница** заходит на http://localhost:3002 и видит всё: кто что взял, когда, и может управлять списком

## 🛠 Технологии

- **Backend:** Node.js, Express, SQLite (better-sqlite3)
- **Frontend:** React, Vite
- **База данных:** SQLite (файловая)

## 📝 API

### Подарки

| Метод | URL | Описание |
|-------|-----|----------|
| GET | /api/gifts | Список подарков (для гостей) |
| GET | /api/gifts/admin | Список подарков с  info о бронировании (для админа) |
| GET | /api/gifts/:id | Получить подарок по ID |
| POST | /api/gifts | Добавить подарок (админ) |
| DELETE | /api/gifts/:id | Удалить подарок (админ) |

### Бронирование

| Метод | URL | Описание |
|-------|-----|----------|
| POST | /api/claims | Забронировать подарок |
| DELETE | /api/claims/:giftId | Снять бронь |

### Системные

| Метод | URL | Описание |
|-------|-----|----------|
| POST | /api/seed | Заполнить базу данных |
